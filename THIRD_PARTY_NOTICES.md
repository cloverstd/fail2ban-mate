# Third-party data and libraries

- **DB-IP City Lite**: downloaded separately at installation/update time from DB-IP. Licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Pages using the results link to [DB-IP](https://db-ip.com). Reduced accuracy and coverage apply. The database is not embedded in project releases.
- **Natural Earth / world-atlas**: `world-atlas` distributes Natural Earth vector map data (public domain), transformed into TopoJSON. See [world-atlas](https://github.com/topojson/world-atlas) and [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/). The package code is ISC licensed.
- JavaScript and Go dependencies retain their own licenses in the corresponding upstream distributions. This project's MIT license does not replace dependency licenses.
